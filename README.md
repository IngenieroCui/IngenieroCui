### About me

I'm a Systems Engineering student nearing graduation, with professional experience as a junior software engineer and hands-on work on business, academic and institutional systems. I enjoy translating complex processes into software with **clear APIs, reliable data flows, sensible access controls and interfaces people can actually use**.

My main interests are **backend engineering, full-stack applications, applied AI, process automation and rule-based decision systems**. I have worked across web, mobile and server environments, from database modelling and integrations to production deployment and troubleshooting.

> **My focus:** build working software, explain technical decisions clearly, respect data ownership, and keep improving through testing and feedback.
